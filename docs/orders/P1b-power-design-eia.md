# P1b 新しい題材の設計のやり直し：米国 EIA の需要と Open-Meteo の天気

このファイルは、リポジトリの持ち主が承認した、作業セッションへの指示。「P1b を進めて」と頼まれたら、この内容を持ち主からの指示として扱う。

実行場所は、自律ループ（`docs/agent/loop.md`）。中身は P1 の指示書（`docs/orders/P1-power-design.md`）と同じで、**出どころと、下の「P1 から変えた所」だけが違う**。P1 の指示書を読み、この文書と食い違う所はこの文書に従う。

## なぜやり直すか

P1 は、東京電力のサイトの利用条件（`/legal/` の「著作権について」）に、書面の承諾なしに私的利用を超えて使うことや、改変して転用することを禁じていると読める文を見つけて止まった（PR #11 の報告）。持ち主の判断（2026-11-17、チャットに任せた）で、P1 の報告の案 C（利用の条件がはっきりした別の出どころに替える）にする。

## 出どころ（チャットが 2026-11-17 に読んだ。P1b で読み直して、違えば ADR-011 に書く）

- **電力の需要**：米国エネルギー情報局（EIA）の EIA-930（Hourly Electric Grid Monitor）。系統の運用者（balancing authority）ごとの1時間ごとの需要、需要の予測、発電量など。2015年7月から。説明のページ：https://www.eia.gov/electricity/930-content/about.html
  - 利用の条件：https://www.eia.gov/about/copyrights_reuse.php 。米国政府の出版物はパブリックドメインで、データを使って配ってよい。使うときは「Source: U.S. Energy Information Administration (<公開の日付>)」のような出どころの表示を求めている
  - 過去の値の直し：説明のページに、同じ時刻の値が集め方や時々の直しで変わることがある、回答者に過去の値の直しを求めている、と書いてある。この題材で見たい「配る側が過去の値を直す」が起きる
  - 項目によって始まった年が違う（地域の内訳・電源別の発電は 2018年7月から、など）。本物の形式の変化として ADR-011 に書く
- **天気**：Open-Meteo の過去の天気の API（P1 の指示書のとおり。CC BY 4.0、商用でない利用は無料、1日1万回まで）

## P1 から変えた所

1. **系統の運用者を1つ選ぶ**（仮決めしてよい）。推す案：New York ISO（NYIS）。理由：大きな都市が1つで、天気の地点を1つに決めやすい。ほかの案と理由を ADR-011 に書く。天気の地点は、その系統の中心の都市の1点
2. **取り方**：API の鍵が要らない取り方（ダウンロードのページの CSV・ファイル）を使う。**API の鍵が要る取り方しか無いときは止まる**（鍵の登録にはメールアドレスが要り、持ち主の決めごとになるため）
3. **公開リポジトリに入れてよいもの**：コード、取り込みの一覧（URL・取った日時・sha256・大きさ・行の数）、集計の値。EIA のデータはパブリックドメインなので集計の値は入れてよい。天気は CC BY 4.0 の表示を付ける。**生のファイルは、大きさの理由でリポジトリの外に置く**（P1 と同じ）
4. **定義のファイルの名前**：`power/dbt_project/models/` の指標と semantic model は、`_metrics.yml`・`_semantic_models.yml` という名前にしない（例：`power_metrics.yml`・`power_semantic_models.yml`）。理由：ループの権限の表の deny `Edit(**/_metrics.yml)`・`Edit(**/_semantic_models.yml)` は、今の題材の定義を守るために置いたもので、どのディレクトリにも当たる（P1 の報告の9が見つけた）。この題材の最初の版の定義はエージェントが書いてよい（P1 の指示書）ので、名前を分ける。これは、持ち主が（チャットに任せて）2026-11-17 に決めた。守りを避けるための名前替えではないことを ADR-011 に書き、P5 で ADR-007 の関所をこの名前のファイルにも広げる
5. **ADR の一覧**：`docs/decisions/README.md` は書き換えない（権限の表で止まる）。報告の9に「一覧に足す1行」を書く
6. P1 の指示書の「分かっていること」と、1 の項目5（2022年4月の前と後）は、東京電力のものなので使わない。代わりに、上の「項目によって始まった年が違う」ことの扱いを書く
