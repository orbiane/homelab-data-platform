# P1 の仮決め

P1 は、利用の条件の文に当たって止まった（`docs/agent/reports/P1.md`）。設計の10項目は決めていない。ここにあるのは、止まる前に取ったページの置き場所だけ。

## P1-1 取ったページの置き場所（リポジトリの外）

- 日付：2026-11-14
- 決めたこと：利用の条件を読むために取った HTML 3本を、環境変数 `POWER_RAW_DIR` が無ければ `~/homelab-power-raw/` とし、その下の `p1-sample/` に置いた。設計（ADR-011 の項目2）で決める正式な置き場所ではない
- ほかの案：
  - 一時ディレクトリに置く：再起動で消え、持ち主があとで中身を確かめられない
  - 既存の `~/homelab-snapshots/` の下に置く：基準データの複製の置き場所（ADR-006）と混ざる
- 選んだ理由：指示書の「場所は環境変数で受け取る。既定は `~` からの相対」に合わせた。新しい空のディレクトリなので、ほかのものと混ざらない
- 止まる類ではないと判断した理由：リポジトリの中も基準データも変えない。消しても元に戻る（同じページを取り直せる）
- 戻すときに直す所：`~/homelab-power-raw/p1-sample/` の3ファイルを消すだけ。P1 のやり直しと P2 の置き場所は、ADR-011 で決め直す
