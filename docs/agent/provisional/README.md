# 仮決めの記録（ADR-009）

指示書に無い設計判断を、エージェントが推す案で決めて進めたときの記録。分析の段で、エージェントが何を決めたかを数えて見直すために残す。

- 1つの作業で1ファイル：`docs/agent/provisional/<ID>.md`（その作業の PR に入れる）
- 1つの仮決めで1節。番号は `<ID>-1`、`<ID>-2` …
- 止まる類（ADR-009 の決定3）は、ここに書いて進めてはいけない。止まって報告する
- 仮決めが無かった作業は、ファイルを作らず、報告に「仮決め 0 件」と書く

## 1節の形

```markdown
## <ID>-<番号> <決めたことを一言で>

- 日付：
- 決めたこと：
- ほかの案：（少なくとも1つ。それぞれ選ばなかった理由）
- 選んだ理由：
- 止まる類ではないと判断した理由：
- 戻すときに直す所：（ファイルと、この仮決めの上に立つ作業の ID）
```
