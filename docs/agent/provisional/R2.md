## R2-4 見立てと、検出器ごとの分け方

- 日付：2026-11-14
- 決めたこと：見立ては、数字の照合が×なら×、○で検出器が1つでも当たれば「印」、○で当たらなければ○。検出器ごとに、一致・誤検出・別の札・見落とし・当たらず・判定できない・対象外の7つに分ける（合計が本の数）。人の札・印の言葉と検出器の対応は、検出器ごとの正規表現（`LABELS`）で、コミット1で決めた。対応する言葉の無い×は、どの検出器の見落としにも数えない
- ほかの案：(a) 指示書の3つ（一致・誤検出・見落とし）だけ。合計が本の数にならず、「当たったが人は別の理由で×」の本の置き場が無い。(b) 見立てを規則C に寄せ、検出器が当たったら×にする。数字が合って当たった本を、印と×に分ける材料が呼び出しに無い
- 選んだ理由：件数の合計で突き合わせられる。人が書かなかったもう1つの間違いを「別の札」として残せる
- 止まる類ではないと判断した理由：測り方で、人の判定を変えていない
- 戻すときに直す所：`apply_detectors.py` の `view` と分け方、`detectors.py` の各 `LABELS`
